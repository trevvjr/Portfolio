# FES Project React

A Vite-powered React rebuild of the original `FES Project` anime library.

## Features

- React SPA with React Router DOM
- Live search and filtering
- Sort by newest, oldest, A → Z, and Z → A
- Favorites saved in localStorage
- Pagination controls
- Detail pages for each anime item
- Dark/light theme toggle with persistence
- AniList GraphQL data fetch with fallback content

## Setup

1. Open a terminal in `c:\Users\ttdki\OneDrive\Desktop\Portfolio\FES Project React`
2. Run `npm install`
3. Run `npm run dev`
4. Open the local server URL shown in the terminal

## Build

- `npm run build` to build the production bundle
- `npm run preview` to preview the production build locally

# Netflix Clone

A Netflix-style landing page built with React-style components in plain HTML, CSS, and JavaScript.

## How to use

1. Open `index.html` in your browser.
2. The page includes a hero banner and scrolling movie rows.
3. No build tools or dependencies are required.

## Notes

- The site uses React and ReactDOM from CDN.
- Image assets are loaded remotely from TMDB.
- This project is a clone-style UI, not a functional streaming app.
